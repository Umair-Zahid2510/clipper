🔑 Social Accounts & Direct Token Setup Guide

How to get your YouTube OAuth Client ID & Secret

  1. Open Google Cloud Console → YouTube Data API v3 and click Enable.
  2. Go to APIs & Services → OAuth consent screen, choose External, and add your Google email under Test users.
  3. Go to APIs & Services → Credentials → + Create Credentials → OAuth client ID.
  4. Choose Application type: Desktop app (or Web application with Redirect URI http://127.0.0.1:8765/).
  5. Paste your Client ID and Client Secret on the right → click Save Credentials, then click + Connect YouTube Channel.

How to get your TikTok Content Posting API v2 Token

  1. Open TikTok for Developers → create an App and enable the Content Posting API product.
  2. Request scopes video.publish (Direct Post) and video.upload (Inbox Draft).
  3. Generate a User Access Token (`act.xxxx...`) via TikTok OAuth or Sandbox token generator.
  4. Paste your account handle (e.g. @kreekclips) and Access Token on the right to post directly from this dashboard.

How to get your Instagram Reels Graph API Token

  1. Switch your Instagram account to a Creator or Business account linked to a Facebook Page.
  2. Open Meta Graph API Explorer and select your App.
  3. Add permissions: instagram_basic, instagram_content_publish, and pages_read_engagement.
  4. Query GET /me/accounts?fields=instagram_business_account{id,username} to copy your 17-digit IG User ID (`ig_user_id`).
  5. Paste your Handle, IG User ID, and Access Token on the right.
